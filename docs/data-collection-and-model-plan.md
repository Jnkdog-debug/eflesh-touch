# eFlesh 电子皮肤 · 6 维力数据采集与模型训练计划

> 目标：用机械臂 + 六维力传感器（真值）对 eFlesh 磁性触觉皮肤施加受控载荷，
> 采集配对数据，训练从 **15 通道磁场 (µT, ~170Hz) → 6 维力 (Fx,Fy,Fz,Mx,My,Mz)**
> 的回归模型，最终在皮肤上实时输出 6 维力。

## 0. 问题定义与关键假设

| 项 | 设定 | 说明 |
|---|---|---|
| 输入 | 15 通道 ΔB (µT)，可选历史窗口 | 5×MLX90393 的 x/y/z |
| 输出（主目标） | 片级 6 维力，皮肤坐标系 {S} | 单接触点假设 |
| 输出（辅助目标） | 接触位置 (x,y)、接触有无 | 多任务有助于表征学习 |
| 量级假设 | 法向 0~50N、剪切 ±20N、力矩按面积定 | 按你的实际应用改 |
| 不可解情形 | 多点同时接触 | 5 taxel 分辨率下单接触是合理边界 |

**为什么片级而不是每个 taxel 出力**：5 个磁力计共享一块磁体皮肤，各通道读数
是全场磁场的混合，片级 6 维力是最稳的可辨识目标；接触位置作为辅助输出弥补
空间信息。多片拼接时逐片估计后融合。

## 1. 标定工装（M1 的硬件部分）

```
机械臂末端 ── 六维力传感器(FT) ── 刚性探针(球头/平头)
                                        │ 施加载荷
                                        ▼
                    刚性底座 ── eFlesh 皮肤片（固定）
```

- **皮肤固定、探针动**（推荐）：FT 读数经过一次坐标变换就是施加在皮肤上的
  真实 6 维力，与机械臂精度解耦。
- 坐标变换：力矩平移公式 `M_S = R·(M_FT + (p_FT − p_S) × F_FT)`；
  {S} 相对机器人基系的位姿用"球头探针在皮肤已知 N 个点位轻压，最小二乘解
  位姿"一次标定（一次性 10 分钟）。
- 探针备 2~3 种头型（球头 R5/R10、平头），不同头型分开记录（摩擦特性不同）。
- **每次轨迹开始前 FT 清零去偏**（重力/温漂）；若 FT 有温度输出一并记录。
- 安全：机械臂力限幅 + 急停 + 行程软限位，先空跑轨迹再上皮肤。

## 2. 采集内容（覆盖 6 维力空间）

| 类别 | 设计 | 目的 |
|---|---|---|
| A 法向按压网格 | 位置 7×7~9×9（含边缘与 taxel 间隙）× 深度 5~7 档 × 速度 3 档（准静态/中/快） | Fz 主导 + 位置覆盖；速度档抓粘弹性/速率效应 |
| B 剪切 | 8~16 方向 × 深度 3 档 × 位置（中心+4 偏心） | Fx/Fy 与磁滞 |
| C 旋拧/滚动 | 平头探针绕 z 加矩、带摩擦滚压 | Mz；Mx/My 由偏心载荷自然覆盖 |
| D 复合+随机连续 | 法向+随机方向剪切的连续轨迹（和差正弦/随机游走）60~90 min | 填满 6 维空间、真实分布 |
| E 重复性 | 跨 ≥3 天重采核心子集 + 每天重录零漂 | 温漂/蠕变泛化 |
| F 无接触段 | 每段轨迹前后各 ≥5s | 零点/背景估计 |

**量估算**：A ≈ 40min + B ≈ 35min + C ≈ 15min + D ≈ 90min ≈ **3 小时/轮**，
170Hz × 15ch ≈ 180 万帧（~110MB 原始）+ FT/位姿 < 1GB。三轮跨天 ≈ 5~6 小时。

**控制方式**：机械臂若有力控/导纳模式，直接按目标力阶梯走；只有位置控制就
按深度阶梯走、FT 记真值（真值来自 FT，不要求轨迹完美）。

## 3. 同步与录制（M1 的软件部分）

- PC 统一录三路（单进程多线程，同一单调时钟打时间戳）：
  - 皮肤：现有 64B 二进制流（seq+checksum，掉帧可见）@ ~170Hz
  - FT：≥500Hz（按你的采集设备接口）
  - 机械臂位姿：≥100Hz
- **细对齐**：每条轨迹的接触起点在三路里互相关对齐（<5ms 级）；
  进阶方案：ESP32 空闲 GPIO 在轨迹开始打脉冲，FT 采集卡记一路模拟量。
- 存储：HDF5（`skin/ft/pose/ts/events` 五组），零拷贝喂训练。
- 软件：在 logger.py 基础上写 `record_dataset.py`（我来写，见 §7）。

## 4. 数据处理

1. **去基线**：ΔB = B − B₀(t)，B₀ 用无接触段滑动估计（顺带解决温漂）
2. 滑窗：当前帧 + 过去 100~200ms（或直接序列模型）——磁性皮肤的**磁滞/粘弹性
   必须靠历史**，纯单帧模型剪切轴上不去
3. 重采样对齐（皮肤 170Hz ↔ FT 500Hz+），接触段分割，接触标记
4. **覆盖检查**：6 维力空间直方图，稀疏区域补采（D 类轨迹定向补）
5. **划分：按轨迹/按天留出，绝不按帧随机切**（时间相关，随机切=泄漏=虚高）

## 5. 模型（由浅入深）

| 级别 | 模型 | 作用 |
|---|---|---|
| L0 | Ridge 线性：ΔB→6 维力 | 物理下限与可解释基线（近线性区段） |
| L1 | MLP（15+历史 → 6） | 主力基线，<100k 参数，可量化部署 |
| L2 | 时序：1D-CNN / GRU / 小 Transformer，吃 200ms 窗口 | 剪切/扭矩/磁滞的主要提升来源 |
| 不确定度 | 高斯 NLL 输出或深度集成 | 分布外/接近饱和时的置信度 |

- 辅助任务：接触位置 (x,y) + 接触有无（multi-task）
- 指标：各轴 RMSE（N / N·m）、R²、**误差-力幅值曲线、误差-位置热图**；
  留一天泛化（漂移）、留位置泛化（空间外推）是两个必须看的表
- 部署：模型极小，PC 实时 170Hz 毫无压力；后续可量化跑在 ESP32 端

## 6. 里程碑（兼职节奏 ~3 周）

| 里程碑 | 内容 | 验收标准 |
|---|---|---|
| M1（2-3 天） | 工装搭建 + 坐标标定 + `record_dataset.py` | 试采 10min：掉帧 0、三路对齐 <5ms、HDF5 可回放 |
| M2（1 周） | 正式采集 v1（A+B+C+D ≈2h）+ L0/L1 训练 | 法向 RMSE 达标（如 <5% 满量程），剪切出基线数 |
| M3（1 周） | 误差分析 → 补采 + 跨天 v2 + L2 时序模型 | 留一天泛化指标；剪切/扭矩误差较 L1 下降 |
| M4（2-3 天） | 实时推理可视化（皮肤估计 vs FT 真值同屏）+ 冻结 v1.0 | 在线延迟 <10ms；文档+模型入库 |

## 7. 风险与坑（前人踩过的）

1. **磁滞/蠕变**：必须带历史窗口 + 采集时覆盖多速度，否则快/慢载荷下误差分裂
2. **零漂/温漂**：上线时用无接触段自动更新 B₀（在线零点）
3. **FT 过载与漂移**：量程确认、每轨迹清零；冲击轨迹前检查饱和
4. **数据泄漏**：按帧随机切分会让指标虚高到不可信——只按轨迹/天划分
5. **机械谐振**：接触振动可能落在皮肤带宽内，训练/推理滤波要一致
6. **探针不垂直**：没关系——真值来自 FT 而不是轨迹指令，但设计上要覆盖到
   各种侧向分量
7. **多接触**：超出单接触假设的数据（故意两手按）单独标注，可做 OOD 测试集
